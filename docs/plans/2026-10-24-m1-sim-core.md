# M1 sim core: implementation plan

Builds milestone 1 of [the v1 spec](../design/v1-spec.md) §8: map, clock,
needs, money, places, every §3 action with fake brains, and save/resume.
$0 of AI. Each step is test-first (Vitest): write the failing test, then the
code.

## Stack

- TypeScript run directly by Node ≥ 22.18 (built-in type stripping), so there
  is no build step and no runtime dependency.
- SQLite through Node's built-in `node:sqlite`: one file at
  `$KAMPUNG_HOME/kampung.db` (default `~/.kampung`).
- Dev only: `typescript` (typecheck), `vitest`, `@types/node`.

## Layout

| Path | What |
|---|---|
| `src/sim/money.ts` | integer cents, `$1.20` / `20¢` formatting |
| `src/sim/rng.ts` | seeded, serialisable RNG (mulberry32) |
| `src/sim/time.ts`, `clock.ts` | game minute ↔ Singapore time, night, injected clocks |
| `src/sim/items.ts` | goods, food values, recipes, lorry price list |
| `src/sim/map.ts` | 40×30 tile map, places, pathfinding |
| `src/sim/state.ts` | world state types and seed world |
| `src/sim/needs.ts`, `tick.ts` | per-minute world advance: needs, activities, lorry, night |
| `src/sim/actions/` | every §3 action: validation with in-world refusals |
| `src/sim/perception.ts` | what a resident perceives (in-world only) |
| `src/sim/skip.ts` | quiet catch-up after downtime (no replay) |
| `src/brain/` | `Brain` interface and the seeded fake brain |
| `src/feed/feed.ts` | event → story-feed line templates |
| `src/store/` | SQLite save/load, event log, money ledger |
| `src/town.ts` | wires state + brains + store; tick loop |
| `src/cli/sim.ts`, `serve.ts` | fast sim with feed output; real-time server |

## Steps

1. Money, RNG, time/clock (tests: formatting, determinism, SGT hours, night).
2. Items and map (tests: 40×30, all places present and reachable, 10 houses).
3. World state + needs + tick (tests: hunger/energy rates, collapse, night
   routine, 06:00 wake, lorry 07:00–07:30).
4. Actions, one group at a time (tests: an accept and an in-world refusal per
   action, plus a guard that no refusal text reads like a system error).
5. Perception + fake brain (tests: perception carries no ids or system words;
   brain is deterministic for a seed).
6. Feed templates (tests: sample lines, notable markers).
7. Store + resume (tests: save → reload is identical; split run equals
   continuous run; long gap skips quietly without replaying).
8. Town integration (test: 3 game days on a fixed seed, no exceptions, money
   conserved except through the lorry).
9. CLI (`npm run sim -- --days 3`), CI job (`typecheck` + `test`).
